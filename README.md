# VHDL ALU System

## Overview

This project implements an Arithmetic Logic Unit (ALU) system using VHDL, integrating a controller, datapath, accumulator, and memory.

The design was developed as my first major digital hardware project after completing my introductory Digital Systems course at Weber State University.

The system follows a **structural design approach**, building the overall architecture through the interconnection of smaller, independently defined hardware modules.

## Hardware and Software

- **Hardware Description Language:** VHDL
- **Development Environment:** Xilinx Vivado
- **Design Methodology:** Structural and hierarchical hardware design
- **Verification:** Behavioral simulation

## System Architecture

The system consists of several interconnected components:

### 1. Arithmetic Logic Unit (ALU)

Performs arithmetic and logical operations on 8-bit data, including:

- Addition
- XOR
- Load
- Hold

These operations are implemented using individual functional modules integrated into the ALU architecture.

### 2. Datapath

The datapath handles the movement and processing of data throughout the system. It integrates the ALU, accumulator, and memory components.

### 3. Controller

The controller coordinates the system's operations using a finite state machine (FSM).

It is organized into modules responsible for next-state determination, state storage, and output decoding.

### 4. Accumulator

Stores intermediate results generated by the ALU, allowing data to be retained and reused during subsequent operations.

### 5. Memory

Provides data storage within the system and interfaces with the datapath.

### 6. Top-Level Integration

The top-level module connects the controller, datapath, and supporting components into a complete digital processing system.

## Design Methodology

One of the main characteristics of this project is its **structural implementation**.

Rather than describing the entire system within a single behavioral module, the design was constructed hierarchically, with individual components interconnected to perform the required operations.

This approach helped me develop a deeper understanding of:

- Hierarchical digital system design
- Component instantiation and interconnection
- Control and datapath separation
- Finite state machine implementation
- Arithmetic and logical hardware operations
- Data storage and register-based processing

## Simulation and Verification

The project was developed and tested through behavioral simulation in Xilinx Vivado.

Simulation was used to evaluate the interaction between the controller, datapath, ALU, and memory.

The design was not implemented on a physical FPGA board.

## Reflections and Future Improvements

As my first major project following an introductory Digital Systems course, this design represents an important step in my development as an Electrical Engineering student.

The emphasis on structural design allowed me to explore the internal organization of a digital system and understand how relatively simple hardware components can be combined to implement more complex functionality.

While the architecture could be improved in terms of modularity, efficiency, and overall organization, the project provided valuable experience in digital hardware design, VHDL programming, and system-level integration.

Future improvements could include simplifying portions of the architecture, improving the verification process, and implementing the system on a physical FPGA.
